# Rubrica: Roteiro de Short

0–5 por critério. **Mínimo: 20/25**, e os critérios ⛔ precisam ter nota ≥ 4.

| Critério | 5 = |
|---|---|
| ⛔ Primeira frase (0–1,5 s) prende sem contexto | Gera um "espera, o quê?" imediato |
| Uma ideia só | Não dispersa |
| ⛔ Payoff no final | Recompensa quem ficou |
| Loop de replay | Última frase emenda na primeira |
| Ritmo visual (≤ 2 s por plano, legendas) | Marcações de cena comprovam |
