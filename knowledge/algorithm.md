# Como o YouTube distribui vídeos (modelo mental operacional)

> Status: base de mercado consolidada até 2026. Toda afirmação abaixo é heurística de trabalho; nossos próprios dados (`learnings.md`) têm precedência.

## O princípio
O sistema de recomendação não "promove canais": ele tenta prever **o que cada espectador vai assistir e ficar satisfeito**. Um vídeo ganha distribuição quando, para as pessoas a quem é mostrado, ele gera clique **e** tempo assistido **e** satisfação, de forma melhor que as alternativas.

## Superfícies de tráfego
| Superfície | O que pesa | Implicação |
|---|---|---|
| Início (home) | CTR + retenção + satisfação para aquele perfil | Embalagem forte, tema de interesse amplo dentro do nicho |
| Sugeridos (ao lado / depois de outro vídeo) | Relação com o vídeo atual, sessão continuada | Temas adjacentes a vídeos populares do nicho; telas finais |
| Pesquisa | Relevância ao termo + desempenho | Título com termo buscado; útil para vídeos perenes |
| Feed de Shorts | % que assiste vs. desliza, replays, engajamento | Frame 0 e primeira frase decidem |
| Inscrições/notificações | Fidelidade | Cresce com o tempo; não conte com isso no início |

## Sinais que controlamos
1. **CTR de impressões**: título + thumbnail. É relativo ao contexto: o CTR cai naturalmente quando o vídeo é mostrado a públicos mais frios. CTR caindo enquanto as impressões sobem pode ser bom sinal.
2. **Retenção**: % média assistida e a forma da curva. Os primeiros 30 s são o maior ponto de perda.
3. **Satisfação**: pesquisas, likes/dislikes, "não recomendar", retorno do espectador.
4. **Sessão**: o espectador continua no YouTube depois? Telas finais e playlists ajudam.

## Implicações para canal novo
- Os primeiros vídeos são testados com amostras pequenas. É normal ter poucas views; o que importa é a **tendência relativa** entre os nossos vídeos.
- Constância cria mais oportunidades de teste; ela não é "recompensada" por si só.
- Um vídeo pode "pegar" semanas depois (tráfego de sugeridos ou pesquisa). Não apague vídeos fracos.
- Mudar de nicho drasticamente confunde o público semente. Varie o ângulo, não o nicho.
