# Protocolo: Roteiro de Short

**Agente:** scriptwriter · **Formato:** vertical 1080x1920, 20–50 s (máx. 60 s, salvo se um learning indicar outra faixa)

## Leitura obrigatória
`knowledge/shorts.md`, `rubrics/script-short.md`, `learnings.md` (tipo shorts).

## Estrutura obrigatória
1. **Frame 0 / 0–1,5 s:** o gancho visual e verbal já é o assunto. Sem introdução, sem logo, sem "neste vídeo".
2. **0–3 s:** afirmação ou pergunta que cria tensão.
3. **Desenvolvimento:** 1 ideia só, ritmo de corte ≤ 2 s por plano, legendas grandes palavra a palavra.
4. **Payoff** nos últimos 20%.
5. **Loop:** a última frase deve conectar com a primeira, para estimular o replay.
6. Sem CTA verbal longo. Opcional: vincular o vídeo longo relacionado (recurso "related video" no upload).

## Fontes de shorts (por prioridade)
1. Recorte do longo da semana (reescrito para funcionar sozinho, nunca um corte cru que dependa de contexto).
2. Fato isolado de alto impacto do backlog.
3. Outlier de shorts de concorrentes, com ângulo próprio.

## Definition of Done
- [ ] Texto ≤ 130 palavras (aprox. 50 s).
- [ ] A primeira frase funciona sem nenhum contexto.
- [ ] Loop final verificado (a última frase lida antes da primeira faz sentido).
- [ ] Fontes em `sources.md` do vídeo-mãe ou do próprio short.
- [ ] Nota na rubrica ≥ mínima.
